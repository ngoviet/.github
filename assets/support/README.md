# Support assets

Shared images for the "Support the project" section of every ngoviet repository.
Generated by `make_support_svgs.py` with the palette-axi `neon-dark` palette (7/7 rules).
The VietQR card re-draws the original MB Bank payload as vector and is verified by decoding it back.

Insert or update the section in a repository with `support_block.py <repo dir> <repo name>`;
it is wrapped in `<!-- support:start -->` / `<!-- support:end -->` markers.
