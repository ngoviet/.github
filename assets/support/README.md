# Support assets

Shared images for the "Support the project" section of every ngoviet repository.
Generated by `make_support_svgs.py` with the palette-axi `neon-dark` palette (7/7 rules).
The VietQR card re-draws the original MB Bank payload as vector, and the Crypto card encodes the BNB Smart Chain (BEP20) wallet address; both QR codes are verified by decoding them back.

Insert or update the section with `readme-axi/readme_axi.py support <repo dir> --write`;
it is wrapped in `<!-- support:start -->` / `<!-- support:end -->` markers.
